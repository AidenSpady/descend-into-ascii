# descend-into-ascii

An experimental ASCII art generator that uses PyTorch and gradient descent
to optimize character placement against a target image.

## Roadmap

- [ ] Build a basic brightness-based ASCII converter
- [ ] Learn Pillow image processing
- [ ] Render characters as font bitmaps
- [ ] Learn PyTorch tensors and gradients
- [ ] Implement soft character selection with softmax
- [ ] Optimize character placement with gradient descent
- [ ] Add example images and documentation
